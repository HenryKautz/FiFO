# FiFO

FiFO is a finite-domain first-order logic language that compiles to propositional CNF for SAT solving. The interpreter is written in Common Lisp (SBCL).

## Project Structure

- `lisp/` — All Lisp sources and the SatPlan axioms (the installable library):
  - `lisp/FiFO.lisp` — Main interpreter: parser, CNF generation, SAT integration, answer extraction. `solve` takes solver keywords (`:solver :cnf-format :preprocessor :preprocessor-techniques :timeout`) that bind the matching globals for the call. A `.wff` CANNOT set any of these: solving policy is the caller's, and `parse-option` rejects the five (plus `*solver-abbreviations*`, listed in `*solve-policy-options*`) with an error naming the replacement. It used to allow them, and because options run during parsing they beat everything — defeating `solve.sh`/`map.sh`'s solver-kind check (which sees only argv) and overriding `planner.lisp`, which `setq`s `*solver*`/`*cnf-format*` and THEN parses the wff, so a file won at every horizon. `.wff`-settable options are now only the generation ones: `*compact-encoding*`, `*tracing*`, `*satplan-numslices*`. `propositionalize` takes `:cnf-format` to override the `(OPTION WEIGHTS ...)` line `instantiate` stamps into the `.scnf`; without it the file's recorded format wins (the global `*cnf-format*` is NOT consulted there), so one `.scnf` can be emitted as CNF, WCNF and WCNF-OLD without regenerating. `*solver-timeout*` (default 600 s; 0/-1/nil = unlimited, normalized by `solver-time-limit`) bounds EVERY solver run and is enforced in-process via `sb-ext:run-program :wait nil` + SIGTERM then SIGKILL after `*solver-kill-grace*` — not by shelling out to `timeout`, which is absent on macOS. SIGTERM is the right signal because anytime MaxSAT solvers print their best-so-far model on it. `*preprocessor*` runs MaxPre 2 (preprocess → solve → **reconstruct**); reconstruction is mandatory since MaxPre renumbers variables, and skipping it yields a plausible WRONG answer rather than an error. MaxPre's `reconstruct` parses only `s OPTIMUM FOUND` and needs an `o` line, so `maxpre--reconstruct` normalizes o/s/v before the call and restores the solver's real status after. Preprocessing is barred from the WMC path — MaxPre preserves optimum cost, NOT model count, so it would silently corrupt Z and all marginals; it also errors if `*cnf-format*` is CNF. `weight`/`probability` accept an arbitrary **formula** (not only a literal): a compound argument is reified by `reify-formula` into a fresh interned atom `(WEIGHTED-FORMULA n)` with the count-neutral biconditional `A ⇔ φ` (expanded with `*compact-encoding*` off so no gensyms leak into the `~S` scnf round-trip), and the weight/target rides on `A` (so `P(A)=P(φ)`); literals are unchanged. Still barred from `or`/`not`/`implies`/`equiv` (now an explicit error). These aux atoms are hidden from the default `marginals` listing, shown under `--weighted-only`.
  - `lisp/pddl2fifo.lisp` — PDDL → FiFO wff translator (SatPlan); supports non-recursive `:derived-predicates` (axioms) — `(:derived (P ?args) <GD>)` reified per-slice as `(equiv (holds (P args) s) <body>)`, a third predicate class kept OUT of the `fluents` domain (no frame axioms), usable in goals/constraints/preferences/evidence/derived bodies but not action preconditions/effects/`:init`; recursion, effect/precondition/init uses rejected; supports the PDDL 3.0 con-GD grammar in `:constraints` (`and`/`forall` over the modals; full goal descriptions incl. `forall`/`exists` inside modals, the problem `:goal`, and preference bodies — static-predicate atoms in formulas stay bare literals resolved at instantiation); `:pddl-evidence` translates PDDL modal evidence forms (`translate-evidence-form`: always/at-end/hold-during/occur-sometime/never/at, combined with and/forall, plus the ground-only `occur-in-order` — ordered action observations compiled to determined ObsDone monitor atoms via biconditional progression axioms, count-neutral under WMC — and its negation `(not (occur-in-order …))`, which flips the final assertion to `¬ObsDone(k,numslices)` for R&G's does-not-comply case used by `recognize.sh`) to FiFO and returns them (3rd value) for the planner's separate evidence scnf
  - `lisp/planner.lisp` — smallest-horizon planning driver; also tier-3 conditioning (`--evidence`/`--evidence-file` FiFO forms, or `--pddl-evidence`/`--pddl-evidence-file` PDDL modal forms translated via pddl2fifo, instantiated via `parse-same-env` into a separate `<root>-evidence.scnf`) and `--marginals` (weighted model counting via `--counter maxent|addmc|ddnnf|d4|mc-sat` — the same back ends `marginals.sh --solver` offers; a counter is NAMED, never a path — each external one resolves on PATH through `*addmc*`/`*d4*`/`*walksat*` so it matches every other entry point, and an unknown name is an error. (The old catch-all treated any unrecognised name as an ADDMC path, so `--counter d4` tried to run d4 AS an ADDMC.) `--marginals` loads ddnnf.lisp too)
  - `lisp/reweight.lisp`, `lisp/maxent.lisp` — weight-learning pipeline; `maxent.lisp` also has `(marginals ...)` (exact marginal inference by enumeration)
  - `lisp/plearn.lisp` — PDDL weight-learning orchestrator (`learn-pddl`)
  - `lisp/mcsat.lisp` — FiFO→MC-SAT bridge: `(marginals-mcsat ...)`, the one **approximate** marginal back end. Shells out ONCE to WalkSAT v58's `-mcsat` mode (which carries the whole MC-SAT loop — outer slice sampling + inner SampleSAT — in C), so a single run yields every marginal. Encoding: MC-SAT rewards satisfaction with non-negative weights (`P(x) ∝ exp(Σ satisfied soft weights)`), so a FiFO cost θ on literal L becomes the soft UNIT clause `¬L` weight θ when θ>0, or `L` weight −θ when θ<0 — same `exp(−θ):1` odds, never a negative weight (MC-SAT's `1−e^{−w}` slice needs `w ≥ 0`); hard clauses + evidence get the `h` prefix. Supports `evidence`/`evidence-file`, `weighted-only`, `scale`, and pass-through sampler flags (`samples`, `burnin`, `seed`, `unitprop`, `walk-prob`, `temp`, `cutoff`). Prints the sampler's `c` diagnostics as `;` comments and **warns when the ESS efficiency is below `*mcsat-efficiency-warning*` (0.1)** — a frozen chain gives wrong marginals, not just noisy ones. Binary found on PATH as `walksat` (`*walksat*`); v57 and earlier are detected and refused (they print help and ignore `-mcsat`). **CDCL seeding** (`seed-from-sat`, default on; `--no-sat-seed` to disable): the hard clauses are solved once with `*solver*` (kissat) and the model passed via walksat's `-init`, because local search alone cannot reach a model of a SatPlan encoding (pb1 survived 400 M flips); a CDCL UNSAT verdict is then a proof, reported immediately. **Do not trust a FROZEN verdict's marginals:** on large SatPlan encodings the chain starts but never moves, returning the seed plan with every marginal pinned at 0/1 — ESS cannot see this (no non-deterministic vars to estimate from), so v58 reports a separate `c mixing:` Hamming-distance line, and `mcsat--frozen-p` surfaces it as a loud warning and a third return value. `--unitprop` makes the check decisive (its free-variable count separates "determined" from "frozen"), so prefer it on
  - `lisp/maxterm.lisp` — FiFO→max-term bridge: `(marginals-maxterm ...)`, `--solver max-term`. NOT a Gibbs marginal — `logit P(a) = beta*(c_min(¬a) − c_min(a))` from 1+n MaxSAT solves (the unconstrained optimum supplies one polarity per atom), i.e. R&G's recognizer with the hypothesis replaced by an atom. Drops the degeneracy term, so it approximates what the WEIGHTS contribute and discards what the COUNTING contributes — on an unweighted theory it returns 0.5 for everything. Output is `(MAXTERM-MARGINAL ...)` deliberately, so `grep MARGINAL` cannot pick it up. Exact on backbone atoms (flagged `[proved]`). Exclusive groups are DETECTED from the theory (at-least-one clause + pairwise at-most-one), never declared in the query — the exact back ends need no declaration, so the query should not repeat what the theory says; `--verify-groups` proves them by SAT instead. At-most-one-but-not-exhaustive groups get a virtual "none" cell. Priors are post-hoc log-odds shifts needing NO re-solve, because a unit cost factors out of the minimisation — exact for the atom it is on, wrong for every other. Uses FiFO's `shift-and-scale-weights`/wcnf writer: raw real weights make a MaxSAT solver emit no objective at all. **Needs an EXACT MaxSAT solver** — default `bin/rc2-maxsat.py` (PySAT RC2, core-guided, prints `s OPTIMUM FOUND`), found beside the script rather than on PATH since FiFO ships it; `--maxsat-solver` selects another. The anytime solvers (tt-open-wbo-inc, nuwls-c) NEVER prove optimality, and since the estimator is a DIFFERENCE of two minima their upper bounds do not cancel; `mt--solve` returns `:unproved` for those and `marginals-maxterm` counts and warns. (Measured on pb1: 15 of 16 solves unproven with the anytime solver, though the values happened to be identical — and rc2 was 2.7x faster.) EvalMaxSAT works, but on macOS ONLY when built with Homebrew GCC — the Apple-clang build compiles cleanly and segfaults instantly, so install-solvers.sh passes a `g++-N` to its cmake (`/usr/bin/g++` is a clang shim). It exits 30 on success, which is fine since `solver-verdict` reads the `s` line.
  - `lisp/wmc.lisp` — FiFO→ADDMC bridge: `(wmc ...)` weighted model count and `(marginals-addmc ...)` marginals via the external ADDMC counter (emits MCC weighted CNF, shells out, parses the count)
  - `lisp/ddnnf.lisp` — FiFO's own pure-Lisp d-DNNF compiler + circuit evaluator (no external binary). `(ddnnf-compile ...)` trace-compiles the hard clauses (grown from maxent's DPLL: decisions→OR, disjoint components→AND, component cache→DAG; smooth-by-construction) into a circuit; `(ddnnf-query ...)`/`(ddnnf-marginals ...)` get Z and ALL marginals in two passes. Unit-literal evidence reuses the compiled circuit (compile-once/query-many); non-unit evidence recompiles from the stored clauses. `(ddnnf-save ...)`/`(ddnnf-load ...)` persist a circuit to a readable `.dnnf` file (`(ddnnf-marginals-sets ...)` queries many evidence sets against one compile). Node cap `*ddnnf-node-limit*`; FiFO-scale instances only — use ADDMC for large/high-treewidth ones. `(ddnnf-compile-d4 ...)` is an alternative producer: it shells out to the external **d4** (d4v2) compiler (`*d4*`, on PATH), parses + smooths its arc-format dump into the SAME struct, so all of query/evidence/persistence is reused (d4 compiles only the Boolean structure; weights stay on the FiFO side). `ddnnf-marginals` takes `:compiler :home|:d4`
  - `lisp/satplan.wff` — domain-independent SatPlan axioms (a runtime dependency)
- `bin/` — Shell scripts: `solve.sh` (satisfiability CLI: fixes plain CNF, default `kissat`) and `map.sh` (MAP inference CLI: fixes weighted CNF, default `tt-open-wbo-inc-Glucose4_1`, `--preprocessor maxpre`, and prints the TRUE cost = raw objective/scale + offset by pinning `scratch-file` so it can read the wcnf's comment lines — note that root must contain no `.`, since FiFO derives `.satout` from the FIRST dot in the path); both render the answer via `fifo-answer.sh` (`_fifo_print_answer`): the `.answer` file VERBATIM plus leading `;` comment lines, so `grep -v '^;'` is exactly the machine-readable form — needed because `solve` returns only the verdict symbol, so printing its return value alone DISCARDS `prove` answer-extraction bindings. Both refuse a solver of the wrong kind via `fifo-solvers.sh` (`_fifo_solver_kind` checks MaxSAT patterns FIRST so `tt-open-wbo-inc-Glucose4_1` is not misread as "glucose"; `_fifo_resolve_solver` mirrors `*solver-abbreviations*` — keep in step). The failure they prevent is silent: weights in a plain `.cnf` become `cw` comments a SAT solver ignores, yielding a non-optimal model. `planner.sh` (planner CLI), `learn.sh` (scnf weight-learning CLI), `learn-pddl.sh` (PDDL weight-learning CLI), `marginals.sh` (marginal inference on an scnf; `--solver maxent` enumeration (default), `--solver addmc`, `--solver ddnnf` (FiFO's own d-DNNF compiler), or `--solver d4` (compile the structure with the external d4 compiler, same circuit machinery); `--save-circuit`/`--circuit` persist & reuse a compiled circuit for ddnnf/d4; `--solver mc-sat` is the approximate MCMC back end — one WalkSAT-v58 `-mcsat` run gives all marginals, with `--samples`/`--burnin`/`--seed`/`--unitprop`/`--walk-prob`/`--temp`/`--samplesat-cutoff`/`--init-cutoff`/`--init-tries`/`--no-sat-seed`), `wmc.sh` (weighted model count / partition function via ADDMC), `recognize.sh` (Ramírez & Geffner plan recognition: for each hypothesis derived predicate hypI it calls `planner.sh` twice — cheapest complying vs. non-complying plan, `--pddl-evidence '(occur-in-order …)'` vs `'(not (occur-in-order …))'` — and forms the calibrated posterior `σ(β·(c(¬O)−c(O)))·prior`, normalized over the disjoint hypotheses; the tractable MaxSAT approximation to the intractable Z_G-normalized WMC posterior), `cleanupfifo.sh` (delete intermediate files), `install-solvers.sh` (clone/build/install the external solvers — kissat, tt-open-wbo-inc, NuWLS-c, **WMaxCDCL** and EvalMaxSAT (the two EXACT MaxSAT solvers, which unlike the anytime ones print `s OPTIMUM FOUND`; WMaxCDCL must be built with `make r`, NOT the README's `make rs` — the static target cannot link on macOS — and its shipped binaries are Linux ELF), ADDMC, d4, WalkSAT v58, MaxPre 2, and `rc2` = `pip install python-sat`, which is NOT a clone/build but IS included because bin/rc2-maxsat.py is max-term's DEFAULT solver — into `~/bin`, checkouts under `Solvers/` (gitignored; `FIFO_SOLVERS` relocates them); skips ones already usable unless `--all`, never lets one failure stop the rest, prints a summary; per-solver usability checks, not bare `PATH` presence — a walksat without `-mcsat` counts as missing), `run_regression_tests.sh`
- `Makefile` — `make install` copies `bin/` → `~/bin` and `lisp/` → `~/lib/fifo/lisp` (override `BINDIR`/`LISPDIR`)
- `SatPlan/Examples/` — example PDDL domains/problems; `Plan_Recognition/` holds the Ramírez & Geffner recognition benchmarks (BlockWords, IntrusionDetection) plus `make-recognition-instance.lisp`, which turns a dataset problem (domain + `template.pddl` + `hyps.dat` + an `occur-in-order` evidence file) into a full recognition instance — uniform-cost domain (Boltzmann model), disjunctive goal over all hypotheses, and incremental `evidence-<i>.txt` files (the generated `*Costs/` dirs)
- `Probability/` — probabilistic-layer docs (`probability.md` — the practice guide for MAP inference, marginal inference, and weight learning; `probability-background.md` — the theory, incl. §3.3 on MAP/MPE vs. marginal MAP, the zero-temperature limit, and MAP as the learning oracle; it documents only machinery FiFO HAS, so proposals live in `discussion.md` instead — projected inference over action variables moved there) and example `.scnf` files
- `*.wff` — FiFO formula input files
- `*.scnf` — Symbolic CNF output files (intermediate)
- `*.cnf` — DIMACS CNF files (input to SAT solver)
- `*.satout` — SAT solver output
- `README.md` — Full language reference and user guide
- NOTE: `satisfy`'s verdict comes from `solver-verdict`, which reads the DIMACS `s` line FIRST and only then falls back to `verdict-by-scan` (whole words SATISFIABLE/UNSATISFIABLE, or a line that is exactly SAT/UNSAT). Do NOT revert to scanning the file for the substring `SAT`: every MaxSAT solver's banner says "MaxSAT", so a run that printed a banner and no verdict was read as SAT — which on a `prove` form silently turned an entailment into a COUNTEREXAMPLE.
- `software-components.md` — every script with its full option list, the Lisp modules, and the catalog of external solvers (SAT / MaxSAT / model counters / knowledge compilers / MC-SAT sampler) with sources and installation notes. The solver catalogs were moved here out of `README.md`, which now points at it.
- `tests/` — All test infrastructure (see below)

**Locating the lisp:** the shell scripts find the lisp via the `FIFO_LISP`
environment variable. `bin/planner.sh` defaults it to the installed
`~/lib/fifo/lisp`; the test scripts default it to the source checkout's `lisp/`
so they exercise the working copy. Set `FIFO_LISP` to override either.

## Key APIs (in lisp/FiFO.lisp)

- `(parse schemas &key static-list)` — Parse FiFO forms to ground clauses (all post-first args are keyword args; `:observation-list` is a deprecated synonym)
- `(instantiate "file.wff")` — File-based: wff -> scnf
- `(propositionalize "file.scnf")` — File-based: scnf -> DIMACS cnf + map
- `(satisfy "file.cnf")` — Run SAT solver (default: kissat)
- `(interpret "file.satout")` — Map SAT output back to symbolic literals
- `(solve "file.wff")` — End-to-end: wff -> solution

## Running

Requires SBCL with Quicklisp. The SAT solver defaults to `kissat` (configurable via `sat-solver` variable).

The weighted-model-counting bridge (`lisp/wmc.lisp`, `bin/wmc.sh`, `marginals.sh --solver addmc`) shells out to a separate **ADDMC** executable — a macOS fork at `github.com/HenryKautz/ADDMC` (built locally at `../ADDMC/addmc`). It is found on `PATH` as `addmc` (the `*addmc*` lisp variable names it — no env var, no `--*-bin` flag: use a different build by putting it earlier on `PATH`). ADDMC is optional — only the WMC features need it.

`marginals.sh --solver mc-sat` (and `marginals-mcsat` in `lisp/mcsat.lisp`) shells out to **WalkSAT version 58 or later** — `gitlab.com/HenryKautz/Walksat`, the `Walksat_v58_MC-SAT` directory, built locally at `../Walksat/Walksat_v58_MC-SAT/walksat`. Found on `PATH` as `walksat` (the `*walksat*` lisp variable). Optional — only `--solver mc-sat` needs it. A pre-v58 walksat has no `-mcsat`, so both the shell script and the test suite probe `-help` for `-mcsat` and refuse/skip rather than silently running the wrong thing.

Similarly, `marginals.sh --solver d4` (and `ddnnf-compile-d4` in `lisp/ddnnf.lisp`) shells out to the **d4** (d4v2) d-DNNF compiler — a macOS fork at `github.com/HenryKautz/d4v2`, whose `demo/compiler` is built locally at `../d4v2/demo/compiler/build/compiler`. Found on `PATH` as `d4` — d4v2 builds it as `demo/compiler/build/compiler` and `install-solvers.sh` installs it under the short name (the `*d4*` lisp variable). Optional — only `--solver d4` needs it. d4 compiles only the Boolean structure; FiFO smooths the dump and applies weights at the leaves, reusing all the ddnnf circuit machinery.

**Important:** SBCL on this system requires `--eval` (long form); `-e` is not recognized and silently drops all eval forms.

## Testing

All test files and scripts live under `tests/`. Two test runners (must be run from inside `tests/`):

```sh
cd tests
bash run-test-instantiate.sh <testname>   # e.g. bash run-test-instantiate.sh test_all_exists
bash run-test-solve.sh <testname>         # e.g. bash run-test-solve.sh test_simple_deduction
```

`run-test-instantiate.sh` runs `instantiate` on `tests_instantiate/<testname>.wff`, writes `tests_instantiate/<testname>.scnf`, and cats the output.

`run-test-solve.sh` runs `solve` on `tests_solve/<testname>.wff`, writes `tests_solve/<testname>.answer`, and cats the output.

`tests/run-test-pddl.sh` (runnable from anywhere) is the PDDL-translator regression suite: for every example problem with a checked-in translation under `SatPlan/Examples/` (LogisticsCosts pb1–pb7, TruckLog, Switch, LogisticsPrefs, Plan_Recognition), it runs `pddl2fifo` on a temp copy and diffs the wff byte-for-byte against the checked-in one (the `(include ...)` satplan path is normalized). Update the checked-in wffs whenever emitter output legitimately changes.

`tests/run-test-evidence.sh` (runnable from anywhere) is the `--pddl-evidence` regression suite, chiefly for `occur-in-order`: behavioral checks (plan embeds the observed sequence at strictly increasing slices; bad evidence raises its contextual error), not gold diffs — evidence clauses can contain session-varying gensyms.

`tests/run-test-mcsat.sh` (runnable from anywhere) is the MC-SAT back-end suite: behavioral, not gold diffs (the output is a Monte-Carlo estimate). Each case fixes `--seed` and asserts the sampled marginals match the exact `maxent` ones to a tolerance — mixed-sign costs, the closed-form `sigmoid(-c)` on a free atom, uniform sampling of pure hard clauses, the header `scale:`, reified formula weights under `--weighted-only`, `--evidence` vs. the same clause asserted, `--unitprop` invariance, seed reproducibility, the ESS diagnostic, UNSAT hard clauses, CDCL seeding on and off, the mixing diagnostic, that a genuinely determined theory is NOT called frozen, and the wrong-version guard. **Skips cleanly (exit 0)** when no WalkSAT v58 binary is found, like the other optional-dependency back ends.

`tests/run-test-options.sh` (runnable from anywhere) is the option / solving-policy boundary suite: each of the six policy options is refused in a `.wff` and the refusal names its replacement, the three generation options are still accepted, an unrecognised option is still a plain `Unknown option`, and `propositionalize`'s `:cnf-format` emits one `.scnf` as CNF / WCNF / WCNF-OLD, falls back to the file's recorded format when omitted, ignores the global, rejects a bad dialect without writing anything, and picks the extension from the effective format. Needs no external solver.

`tests/run-test-weight-formula.sh` (runnable from anywhere) is the formula-valued `weight`/`probability` behavioral suite: the reified biconditional appears, illegal nesting in `or`/`not`/`implies`/`equiv` errors, and maxent learns a formula's weight so `P(φ)` hits its target. Byte-exact instantiate output for these is also covered by the `test_weight_formula` / `test_probability_formula` gold_instantiate cases in `run_regression_tests.sh`.

The full suite runs from the repo root with `bash bin/run_regression_tests.sh` (it tests `lisp/` by default; set `FIFO_LISP` to test an installed copy).

Compare output against gold:
```sh
diff tests_instantiate/<testname>.scnf gold_instantiate/<testname>_gold.scnf
diff tests_solve/<testname>.answer gold_solve/<testname>_gold.answer
```

Test directories under `tests/`:

|---|---|
| `tests_instantiate/` | In-progress `.wff` files for `instantiate` tests |
| `passed_instantiate/` | Verified passing `.wff` and `.scnf` pairs for `instantiate` |
| `gold_instantiate/` | Reference `*_gold.scnf` files for `instantiate` comparison |

### Known issues

- Nested `exists` with `(option compact-encoding 0)` causes exponential clause blowup (cross-product expansion). Keep domains small (≤3 values) or omit the option to use Tseitin encoding.
- `test_nested_exists_nocompact.wff` uses 3 boys / 2 girls to stay tractable with compact-encoding disabled.
- `test_nested_exists_compact.wff` uses full 4-boy / 4-girl domains with compact-encoding enabled.
